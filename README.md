# 栖刻

给自己用的原生 Mac 番茄钟。184 × 210 的透明无边框桌面小时钟，152 点圆形毛玻璃表盘，使用原生 NSVisualEffectView 低不透明度背景模糊，macOS 26 上叠加 NSGlassEffectView 的 clear 玻璃。材质在原生窗口视图中合成，避免 SwiftUI 裁剪与阴影将其离屏渲染成灰色。专注时长可选 25、30、35、40、45 分钟，休息 5 分钟，自动循环。

## 开始使用

双击本目录的 **栖刻.app**，点击「开始专注」。第一次开始时，允许发送系统通知。

- 所选专注时长结束后，提示喝水、起身活动，并自动开始 5 分钟休息。
- 休息结束后，自动开始下一轮所选时长的专注。
- 点击表盘上的播放／暂停按钮，或按空格键开始或暂停。
- 拖动表盘移动位置，自动记住位置；默认置顶，显示在各个桌面。
- 鼠标移入时出现底部工具条，可重置、切换置顶或打开设置；移开后工具条隐藏。
- 右键表盘可控制计时、跳过休息、切换声音、隐藏或退出。
- 菜单栏显示剩余时间；关掉窗口仍会计时，从菜单栏或 Dock 可重新打开。
- 从菜单栏「退出栖刻」或按 ⌘Q 完全退出，退出时暂停计时并取消待发送通知；下次打开可继续。
- 今日次数只统计达到所选时长的完整轮次，重置不会清除已完成记录。
- 配色提供雾银、海蓝、青玉、烟紫、玫瑰五种，可从右键「玻璃配色」、设置或统计面板切换；选择自动保存，透明材质保持不变。
- 右键「今日专注统计」、底部统计按钮、菜单栏入口或 ⌘1 打开统计面板，显示今日专注总时长、完整轮数和每段连续专注记录。最小化、关闭或点击「收起为小时钟」后继续使用桌面小时钟。
- 右键「提前结束专注…」可结束当前一轮并进入休息，已专注的部分按实际时长保留，不记为完整轮数。若原本暂停，则休息也等待手动开始。
- 今日时长实时累加当前一轮，排除暂停和休息；重置前已专注的部分也保留。跨午夜的时间按本地日期拆分，最近 30 天记录仅存本机。

升级会迁移旧版完整轮次记录。旧版没有保存未完成轮次的精确起止时间，升级前的零散时长无法追溯，升级后开始准确记录。

专注时长可在统计面板、设置或右键菜单中选择。修改立即应用本轮，保留已专注的时间；若已达到新的目标时长，则进入休息。选择会随计时状态保存。

到点会显示置顶提醒窗口，保留到点击「知道了」；提醒声音开启时连续播放三次提示音。系统通知权限会在启动和应用激活时检查，面板会显示权限状态和发送错误。可点击「测试提醒」验证弹窗和系统通知，测试不改变计时，并检查通知中心是否收到测试通知。

系统勿扰模式和通知设置可能使提醒静音。电脑睡眠时无法提醒；唤醒后按实际经过的时间恢复循环。睡眠期间跨过的完整专注时段也会计入次数。关闭应用窗口不等于退出应用。

## 构建与验证

适用于 Apple Silicon Mac，macOS 14 或更新版本。仅使用系统 SwiftUI、AppKit、UserNotifications 和 AVFoundation，无额外运行时、账号或网络服务。

安装 Xcode 命令行工具后执行：

```sh
./build.sh
open 栖刻.app
```

构建会先验证计时边界、自动循环、暂停恢复、跨多轮休眠校正、序列化恢复、跳过休息、提前结束、实际时长、暂停排除、跨午夜拆分、旧记录迁移、可选时长、调整时长保留进度及缩短至已达到目标，再生成应用和图标并本地签名。

## 开源复用

按用户要求使用 GitHub CLI 搜索现成项目后，选用 MIT 许可的 [ivoronin/TomatoBar](https://github.com/ivoronin/TomatoBar)。基于提交 `90a77d664dfe33c016bf24f89b0c82e77f9aec84`：

- `Sources/Notifications.swift` 改编自其 `TomatoBar/Notifications.swift`，保留通知代理、分类和跳过休息操作，增加定时通知、自定义提示音和前台展示。
- `栖刻.app/Contents/Resources/ding.wav` 复用其提示音。
- 原始通知代码与 MIT 许可证保留在 `ThirdParty/`，许可证也随应用打包。

为适配固定 40／5 循环、暂停恢复和本地持久化，采用独立的小型计时核心；界面与应用图标为本项目制作。

休息视频：在统计面板或小时钟右键菜单打开「设置休息视频」，粘贴视频链接并保存。专注到点或提前结束进入休息时会用默认浏览器打开链接。留空并保存即可关闭。测试提醒不会打开视频；视频是否自动播放由网站和浏览器决定。
