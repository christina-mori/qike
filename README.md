# 栖刻 · Qike

一个轻巧的原生 macOS 桌面番茄钟，让专注与休息自然交替。

栖刻以透明无边框的小表盘常驻桌面，提供可调整的专注时长、到点提醒和每日专注统计。使用 SwiftUI 与 AppKit 构建，无需账号，计时和记录均在本机完成。

## 功能亮点

- **专注与休息自动循环**：支持 25、30、35、40、45 分钟专注，默认 40 分钟，每轮休息 5 分钟；支持暂停、恢复、重置与跳过休息。
- **玻璃质感桌面时钟**：184 × 210 的透明无边框窗口，152 点圆形毛玻璃表盘；macOS 26 上叠加原生玻璃效果。
- **五种配色**：雾银、海蓝、青玉、烟紫、玫瑰，选择后自动保存。
- **随手可用**：拖动移动并记住位置，默认置顶并显示在各个桌面；菜单栏同步显示剩余时间。
- **到点提醒**：置顶提醒窗口、系统通知和可关闭的提示音，支持测试提醒。
- **每日专注统计**：查看今日累计时长、完整轮数和每段专注记录，最近 30 天记录保存在本机。
- **灵活调整节奏**：修改专注时长会保留本轮进度；提前结束或重置时，已投入的专注时间仍会保留。
- **可选休息视频**：配置视频链接后，进入休息时自动用默认浏览器打开。

## 下载安装

前往 [最新 Release](https://github.com/christina-mori/qike/releases/latest)，下载附件中的 `Qike-v1.0.0-macOS-arm64.zip`，无需安装开发工具或自行编译。

1. 解压 ZIP，将 `栖刻.app` 拖入「应用程序」文件夹。
2. 打开「栖刻」，点击「开始专注」，并允许发送系统通知。

下载版适用于 **Apple Silicon Mac、macOS 14 或更新版本**，不支持 Intel Mac。当前版本仅做本地临时签名，尚未经过 Apple Developer ID 签名和公证；首次打开可能被 macOS 拦截。确认下载来源是本仓库 Release 后，可在「系统设置 → 隐私与安全性」中使用「仍要打开」。受管理的 Mac 可能不允许此操作。

Release 同时提供 `SHA256SUMS.txt`，可用于核对下载文件的完整性。

## 从源码构建

### 环境要求

- Apple Silicon Mac（当前构建脚本面向 arm64）。
- macOS 14 或更新版本。
- 包含 macOS 26 SDK 的 Xcode／命令行工具（源码使用了 `NSGlassEffectView`，运行时会按系统版本启用）。

项目仅使用系统提供的 SwiftUI、AppKit、UserNotifications 和 AVFoundation，无需安装第三方运行时或包管理器依赖。

### 构建步骤

首次构建前，如未安装 Xcode 命令行工具，运行：

```sh
xcode-select --install
```

克隆项目并构建：

```sh
git clone https://github.com/christina-mori/qike.git
cd qike
./build.sh
open 栖刻.app
```

仓库中的 `栖刻.app` 目录包含应用资源，不包含已编译的可执行文件，需要先运行构建脚本。脚本会执行计时核心测试、生成图标、编译应用并进行本地签名。

打开应用后，点击「开始专注」，并允许发送系统通知。

## 使用方式

| 操作 | 方式 |
| --- | --- |
| 开始或暂停 | 点击表盘播放／暂停按钮，或按空格键 |
| 移动时钟 | 拖动表盘 |
| 重置、切换置顶或打开设置 | 鼠标移入表盘，使用底部工具条 |
| 调整专注时长 | 在统计面板、设置或右键菜单中选择 |
| 打开今日统计 | 使用统计按钮、右键或菜单栏入口，也可按 ⌘1 |
| 提前进入休息 | 右键选择「提前结束专注…」 |
| 更换颜色 | 在右键「玻璃配色」、设置或统计面板中选择 |
| 完全退出 | 菜单栏选择「退出栖刻」，或按 ⌘Q |

关闭时钟窗口后仍会继续计时，可从菜单栏或 Dock 重新打开。完全退出应用会暂停计时并取消待发送通知，下次打开可继续。

### 专注统计与时长调整

今日时长实时累加本轮已专注时间，排除暂停和休息。只有达到所选目标时长的完整轮次才会增加完成次数；提前结束和重置会保留已专注的部分，但不会计为完整轮次。跨午夜的记录按本地日期拆分。

修改专注时长会立即应用到本轮，并保留已投入的时间；如果已达到新目标，则进入休息。暂停时提前结束，休息仍需手动开始。

升级时会迁移旧版完整轮次记录。旧版没有保存未完成轮次的精确起止时间，因此升级前的零散时长无法追溯。

### 提醒与休息视频

到点后会显示置顶提醒窗口，直到点击「知道了」；开启声音时连续播放三次提示音。可通过「测试提醒」检查弹窗和系统通知，测试不会改变计时或打开视频。

在统计面板或小时钟右键菜单中打开「设置休息视频」，保存完整的 HTTP 或 HTTPS 视频链接。专注到点或提前结束进入休息时，会用默认浏览器打开链接；清空并保存即可关闭。是否自动播放取决于网站与浏览器设置。

系统勿扰模式和通知设置可能使提醒静音。电脑睡眠期间无法提醒；唤醒后会按实际经过的时间恢复循环，期间跨过的完整专注时段也会计入次数。

## 本地数据

计时状态、偏好和专注记录通过本机 `UserDefaults` 保存，无需登录或云端同步。可选的视频功能会打开你配置的外部网站。

## 开发与验证

```text
Sources/          应用界面、计时核心、通知与设置
Tests/            计时核心测试
Scripts/          应用图标生成脚本
ThirdParty/       复用代码与第三方许可
Info.plist        应用配置
build.sh          测试、编译和本地签名入口
栖刻.app/         应用资源与本地构建输出
```

运行 `./build.sh` 可完成构建与验证。测试覆盖计时边界、自动循环、暂停恢复、跨多轮休眠校正、序列化恢复、跳过休息、提前结束、实际专注时长、跨午夜拆分、旧记录迁移，以及调整专注时长时的进度保留。

构建缓存、应用可执行文件和本地签名产物不纳入版本控制。
